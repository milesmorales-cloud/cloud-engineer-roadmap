# System Health Checker

## Overview

A Python command-line application that monitors CPU usage, memory usage, disk usage, and system uptime. This project is part of my journey toward becoming a Cloud Engineer.

## Features

- CPU usage monitoring
- Memory usage monitoring
- Disk usage monitoring
- System uptime reporting
- Automated unit tests

## Technologies

- Python 3
- psutil
- unittest
- Git and GitHub

## Prerequisites

- Python 3
- The psutil package

## Usage

Run the application from this directory:

```bash
python3 main.py
```

## Testing

Run the automated tests:

```bash
python3 -m unittest discover -s tests -v
```

## Learning Outcomes

- Writing reusable Python functions
- Monitoring system resources
- Formatting command-line output
- Writing automated unit tests
- Using Git for version control
